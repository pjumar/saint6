<task type="auto">
  <name>Task 2: Fix UAT-002 — TestimonialCard Image aspect ratio warning</name>
  <files>
    app/components/testimonial-card/TestimonialCard.tsx
    app/components/testimonial-card/TestimonialCard.module.css
  </files>
  <action>
The Next.js Image component receives `width={120} height={40}` but CSS overrides both to `auto` with max-height/max-width constraints, causing a dev console warning.

Fix by switching the Image to use `fill` layout with a sized container:

1. In `TestimonialCard.tsx`: Wrap the Image in a container `<div>` and change from explicit `width`/`height` props to `fill` prop:
   ```
   <div className={styles.logoContainer}>
     <Image
       src={logoUrl}
       alt={logoAlt}
       fill
       sizes="120px"
       className={styles.logo}
     />
   </div>
   ```

2. In `TestimonialCard.module.css`:
   - Add `.logoContainer` with `position: relative; width: 7.5rem; height: 2.5rem;` (matches existing max-width/max-height constraints)
   - Simplify `.logo` to just `object-fit: contain;` (remove width/height/max-width/max-height since the container handles sizing)

This eliminates the dimension mismatch warning while preserving the same visual layout.
  </action>
  <verify>
1. Run `npm run dev`, navigate to /en/event-planning

3. Logo images in testimonial cards render at same size as before
