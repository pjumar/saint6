<task type="auto">
  <name>Task 1: Create useImageFallback hook</name>
  <files>app/hooks/useImageFallback.ts, app/hooks/index.ts</files>
  <action>
Create a custom hook for handling image load errors with fallback support.

Hook signature:
```tsx
function useImageFallback(src: string, fallbackSrc?: string): {
  currentSrc: string;
  hasError: boolean;
  handleError: () => void;
}
```

Behavior:
- Returns original src initially
- On error, switches to fallbackSrc if provided
- If no fallbackSrc, switches to a default placeholder path
- Sets hasError to true when error occurs
- Memoize handler to prevent re-renders

Default placeholder: `/images/placeholder.svg` (will create simple SVG)

Also create a simple placeholder.svg in public/images/:
- Gray background (#f0f0f0)
- Simple icon or "Image not available" text
- Aspect ratio friendly (square, will scale)

Export via barrel file: app/hooks/index.ts
  </action>

  <done>useImageFallback hook exists, placeholder SVG created, exports work</done>
</task>

Priority components (most visible):

- KeyProjectSection: Project images, team photos - use fallback

Implementation approach:
- For mapped arrays: Track error state per image using object/Map
- For single images: Simple useState for error flag
- Keep it simple - don't over-engineer

Note: Not all Image usages need hooks. Some can use simple inline handlers:
```tsx
<Image
  onError={(e) => { e.currentTarget.style.display = 'none' }}
  ...
/>
```
