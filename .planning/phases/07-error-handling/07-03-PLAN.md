Replace index-based keys with unique identifiers:

   - Team members: Use name or id as key (e.g., `key={member.name}`)
   - Expertise items: Use item text as key (e.g., `key={item}`)
   - Gallery images: Use image src or add id to data (e.g., `key={image.src}`)

2. TrustedBySection.tsx:
   - Brand logos: Use logo name or src as key (e.g., `key={logo.name}`)
   - Duplicated logos for animation: Prefix with position (e.g., `key={\`first-${logo.name}\`}`)

Key selection rules:
- Use unique identifier from data if available (id, name, src)
- For string arrays, the string itself can be the key
- For duplicated items (animation), add prefix to differentiate
- NEVER use array index as key
