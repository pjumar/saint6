Create the foundational page layout and route structure for the Studio Rental service page. This establishes the reusable template pattern that will be used for 4 additional service pages (Phases 3-5). The page follows the Figma design at node 529-4276.

**Dependencies:**

**Key architectural goal:** Build a reusable service page template that can be quickly adapted for Set Design, Production, Event Planning, Decoration, and Creative pages.

**Implementation approach:**

2. Implement proper spacing and container widths (following 90rem max-width from Phase 1)

**Files to create:**

**Success check:**

- No horizontal overflow on mobile
