### Task 1: Implement room card components

**Objective:** Create reusable room card component for studio spaces

**Files to create:**
- `app/components/room-card/RoomCard.tsx`
- `app/components/room-card/RoomCard.module.css`

**Component features:**
1. **Room image** - Placeholder image with proper aspect ratio (449×449px)
2. **Room title** - e.g., "The Loft", "The Studio", "The Arena"
3. **Pricing display** - e.g., "450,000/hour", "800,000/hour"
4. **Room counter** - e.g., "01/06", "02/06", "03/06"
5. **Room specs** - Space (125m²), Width (6m), Ceiling height (4.5m)
6. **Description text** - Brief room description
7. **Action buttons** - "Make a Booking" and "Gallery" buttons
8. **"Enter the Room" overlay** - Circular button overlay for interactive rooms

**Figma reference:**
- Cards in Frame 151, 160, 161 (nodes 547:4717-4731)
- Card dimensions: 448×856px
- Image area: 446×596px
- Content area: 417×256px

**Props interface:**

### Task 3: Implement FAQ accordion and inquiry form

**Objective:** Create collapsible FAQ section and contact inquiry form UI

**Files to create:**
- `app/components/faq-accordion/FAQAccordion.tsx`
- `app/components/faq-accordion/FAQAccordion.module.css`
- `app/components/inquiry-form/InquiryForm.tsx`
- `app/components/inquiry-form/InquiryForm.module.css`

**FAQAccordion component:**
1. Display list of FAQ items:
   - "How do I book?"
   - "What's the cancellation policy?"
   - "Can I visit before booking?"
   - "What's included in the rental?"
2. Expandable/collapsible interaction (click to toggle)
3. One item expanded by default ("What's the cancellation policy?" with Lorem Ipsum text)
4. Smooth expand/collapse animation
5. Support i18n for questions and answers

**FAQAccordion props:**
```typescript
interface FAQItem {
  question: string;
  answer: string;
}

interface FAQAccordionProps {
  items: FAQItem[];
  defaultExpandedIndex?: number;
}
```

**InquiryForm component:**
1. Form fields:
   - Name (text input)
   - Email (email input)
   - Phone (tel input)
   - Preferred date (date input)
   - Message (textarea)
2. Submit button
3. Form validation (client-side only for now)
4. No backend submission yet - just console.log on submit
5. Proper form accessibility (labels, aria attributes)

**Figma reference:**
- FAQ section: Frame 214 (node 596:10661)
- Contact form: Frame 254 area (node 702:10711)

**Success check:**
- FAQ items can be toggled open/closed
- Only one FAQ open at a time (accordion behavior)
- Form fields render with proper types and placeholders
- Form validation works (required fields, email format)
- Submit button shows loading state
- Form layout responsive on mobile
