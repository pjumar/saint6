# Phase 2: Studio Rental Page - Context

**Gathered:** 2026-01-12
**Status:** Ready for planning

<vision>
## How This Should Work

The Studio Rental page follows a showcase + info layout pattern: hero image/video at the top to grab attention, followed by service details, features, a gallery showcasing the studio space, and a contact/inquiry section at the bottom.

This is the first service page, so it establishes the template pattern that will be reused for the next 4 service pages (Set Design, Production, Event Planning, Decoration, Creative). The structure and component patterns created here will accelerate development of Phases 3-5.

The page implements the Figma design at node 529-4276 exactly as specified. The visual style should feel cohesive with the polished homepage from Phase 1.

</vision>

<essential>
## What Must Be Nailed

- **Reusable template pattern** - The page structure, component architecture, and layout approach must be solid and reusable. This isn't just one page—it's the foundation for 4 more service pages. Get the template right so Phases 3-5 can move quickly.

- **Figma design fidelity** - Implement the design at node 529-4276 exactly as specified. All sections, spacing, typography, and layout must match the design.

</essential>

<boundaries>
## What's Out of Scope

- **Booking functionality** - No actual booking system or backend integration. Just the contact/inquiry UI for now. Backend functionality comes in a later phase.

- **Dynamic CMS content** - Hardcode all studio content (text, images, features) for now. CMS integration for dynamic content is Phase 8.

- **Advanced micro-interactions** - Keep interactions and animations straightforward. Focus on getting the layout, structure, and template pattern solid rather than fancy animations.

</boundaries>

<specifics>
## Specific Ideas

**Design reference:** Figma design at https://www.figma.com/design/Svoma9FL1BohckX6LRzpry/Saint-6-STUDIO?node-id=529-4276&m=dev

**Template approach:** Create reusable components and layout patterns that can be easily adapted for the other service pages. Think about what varies between services (content, images) and what stays consistent (structure, spacing, component types).

**Visual consistency:** Carry over the visual style, spacing patterns, and responsive behavior from the polished homepage (Phase 1).

</specifics>

<notes>
## Additional Context

This phase is strategic—it's not just about building one service page, but about establishing the pattern that makes the next 4 service pages (Phases 3-5) fast to implement.

The three plans break the work into:
1. Page layout structure from Figma
2. Service-specific components (Studio Rental content)
3. Responsive verification and i18n translations

After this phase, the template should be proven and ready for rapid replication.

</notes>
