## Tasks

### Task 1: Test responsive behavior across breakpoints

**Objective:** Verify all components adapt correctly to different screen sizes

**Testing matrix:**

| Component | Mobile (375px) | Tablet (768px) | Desktop (1440px) |
|-----------|----------------|----------------|------------------|
| Hero section | Full width, stacked elements | Full width, adjusted spacing | Full width, original layout |
| Stats section | 2-column grid | 3-column grid | 5-column grid |
| Room cards | Single column stack | 2-column grid | 3-column grid |
| Concept room cards | Single column stack | 2-column grid | 3-column grid |
| FAQ accordion | Full width, stacked | Full width, optimized | Two-column layout |
| Inquiry form | Full width, stacked inputs | Optimized layout | Two-column inputs |
| Equipment grid | 2-column grid | 3-column grid | 4-column grid |
| Full rental card | Full width | Full width | Centered, constrained |

**Testing steps:**
1. Open page in browser dev tools
2. Test each breakpoint systematically
3. Check for horizontal overflow using `document.body.scrollWidth`
4. Verify text remains readable (no tiny text on mobile)
5. Ensure touch targets are >44px on mobile (buttons, accordion headers)
6. Test scrolling behavior (smooth, no jank)
7. Verify images maintain aspect ratio

**Files to modify if issues found:**
- Component CSS Modules (adjust media queries)
- Page-level styles (container widths, spacing)

**Success check:**
- No horizontal scroll on any breakpoint
- All content readable and accessible
- No layout breaks or overlapping elements
- Proper spacing maintained across breakpoints
- Images don't distort or cause layout shift

### Task 2: Implement and test Vietnamese translations

**Objective:** Add Vietnamese translations for all Studio Rental page content

**Translation files to update:**
- `app/i18n/locales/vi.json` (add studio-rental section)
- `app/i18n/locales/en.json` (verify English keys)

**Content to translate:**

1. **Hero section:**
   - Tagline: "Your creative playground" → "Không gian sáng tạo của bạn"

2. **Stats section:**
   - "Total Rooms" → "Tổng số phòng"
   - "Ceiling Height" → "Độ cao trần"
   - "Total Space" → "Tổng diện tích"
   - "Blank Rooms" → "Phòng trống"
   - "Concept Rooms" → "Phòng concept"

3. **Intro section:**
   - "How It Work" → "Cách thức hoạt động"
   - Description text translation
   - "Get in touch" → "Liên hệ ngay"

4. **Room cards:**
   - "Make a Booking" → "Đặt phòng"
   - "Gallery" → "Thư viện ảnh"
   - "Enter the Room" → "Vào phòng"
   - Room descriptions

5. **FAQ section:**
   - Question translations
   - Answer translations

6. **Form labels:**
   - "Name" → "Họ tên"
   - "Email" → "Email"
   - "Phone" → "Số điện thoại"
   - "Preferred date" → "Ngày mong muốn"
   - "Message" → "Tin nhắn"
   - "Submit" → "Gửi"

**Implementation approach:**
1. Add all translation keys to `vi.json` and `en.json`
2. Update components to use `useTranslations()` hook
3. Replace hardcoded strings with translation keys
4. Test language toggle on page
5. Verify all text updates when switching languages

**Example translation structure:**
```json
{
  "studioRental": {
    "hero": {
      "tagline": "Your creative playground"
    },
    "stats": {
      "totalRooms": "Total Rooms",
      "ceilingHeight": "Ceiling Height",
      "totalSpace": "Total Space"
    },
    "rooms": {
      "makeBooking": "Make a Booking",
      "gallery": "Gallery"
    }
  }
}
```

**Success check:**
- Page displays in English at `/en/studio-rental`
- Page displays in Vietnamese at `/vi/studio-rental`
- All text translates correctly when switching languages
- No untranslated strings or translation keys showing
- Language toggle works smoothly
- No layout breaks due to longer/shorter translations

## Issues to Watch For

**Common responsive issues:**
- Horizontal overflow on narrow screens
- Text too small to read on mobile
- Images causing layout shift
- Touch targets too small (<44px)
- Cards breaking out of containers

**Common i18n issues:**
- Untranslated strings showing
- Layout breaking with longer Vietnamese text
- Translation keys showing instead of text
- Language toggle not updating all content

**Common interaction issues:**
- FAQ accordion not toggling
- Multiple FAQs open at once
- Form submission not working
- Buttons not responding to clicks
- Keyboard navigation broken
