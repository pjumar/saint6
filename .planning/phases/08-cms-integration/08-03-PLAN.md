**Key Strapi functions:**
- `getCreativePage(locale)`, `getProductionPage(locale)`, etc.
- `getServiceItems(page?, section?)` - services and workflow items
- `getPortfolioItems(page?)` - portfolio for creative, set-design, decor
- `getTestimonialItems()` - testimonials collection
- `getKeyProjects(locale)` - key projects for production, event-planning

**ISG Pattern (established in 08-01, 08-02):**
- Server Component fetches at BUILD TIME
- Data baked into static HTML
- No runtime CMS calls
- Client wrappers for interactive sections (carousels, etc.)
- Dev fallback only for local development
