### Task 3: Create masonry portfolio component
**type:** auto

**Objective:** Build the unique masonry portfolio grid for decoration projects

**Files to create:**
- `app/components/decor-portfolio/DecorPortfolio.tsx`
- `app/components/decor-portfolio/DecorPortfolio.module.css`

**Portfolio structure:**
- Row 1: 2 equal columns (50/50)
- Row 2: 3-column masonry with mixed heights
  - Column 1: short image + tall image
  - Column 2: tall image + short image
  - Column 3: tall image + short image

**Each project card contains:**
- Image with varying aspect ratios
- Category label (uppercase, mono font)
- Project title (uppercase, heading font)

**Implementation:**
1. Create DecorPortfolio component with:
   - `projects` prop for project data
   - CSS Grid for 2-row layout
   - Masonry effect using grid-row spans
2. Style with CSS Modules matching design:
   - 24px gap between items
   - Border-bottom on category labels
   - Responsive: stack on mobile

**Verify:** Masonry grid displays correctly with mixed heights
